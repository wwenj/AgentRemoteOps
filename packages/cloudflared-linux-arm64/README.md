# agent-remoteops-cloudflared-linux-arm64

Pinned `cloudflared` binary used internally by Agent RemoteOps on Linux arm64.

This package is installed automatically as an optional dependency of `agent-remoteops` and is not intended to be installed or invoked directly. Its internal npm bin entry preserves the executable mode during packaging.
